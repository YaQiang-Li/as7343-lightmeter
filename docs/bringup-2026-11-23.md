# AS7343 上板调试记录（2026-11-23）

## 环境

- 板子：`Raspberry Pi 4 Model B Rev 1.4`（`/proc/device-tree/model`），Debian 12 bookworm，
  内核 6.12.25+rpt-rpi-v8
- 初始状态：`/boot/firmware/config.txt` 中 `#dtparam=i2c_arm=on` 被注释，系统里没有 `/dev/i2c-1`
- 处理：备份原文件后取消注释，执行 `sudo dtparam i2c_arm=on` 立即生效，不用重启。I2C1 时钟 100 kHz

## 18 通道读数（64x / 83 ms → 256x）

```
gain 7 astatus 00 dt 0.263 [39, 90, 86, 5, 142, 2915, 13, 39, 62, 112, 142, 2915, 2, 83, 10, 24, 142, 2917]
gain 9 astatus 09 dt 0.252 [160, 367, 354, 22, 575, 11955, 54, 159, 253, 460, 574, 11947, 11, 340, 43, 99, 575, 11930]
```

DATA_5/11/17 是 FD 通道（宽带、面积大，约为 FY 的 30 倍）；增益 ×4 后各通道读数也按 ×4 线性增长。
通道顺序与 DS001046 Figure 57 (CFG20) 一致。

## FD 闪烁 FIFO

```
fd_time 100 bytes 3564 dt 1.002 rate 3558.0 B/s ov 0     # 理论 1/(101*2.78us)=3561 Hz
fd_time 360 bytes  996 dt 1.000 rate  995.5 B/s ov 0     # 理论 996 Hz
fd_time 100 ... ENABLE=0x43 (SP_EN|FDEN|PON): bytes 8    # 同时开 SP_EN 时 FD 不写 FIFO
```

FD_GAIN 扫描（FD_TIME=180）：

```
gain=8  mean 34.7
gain=9  mean 71.3
gain=10 mean 148.6
gain=11 min 0 max 0        # >=1024x 全 0；把 AGC_GAIN_MAX(0xD7) 设为 0xA9 也一样
gain=12 min 0 max 0
```

结论：采样率公式为 (FD_TIME+1)×2.78 µs（与 UG001009 6.13 一致）；驱动的 FD 增益上限定为 512x；
自动增益从低往高爬，零值比例上升就退回一档，避免把 PWM 关断相的 0 误判为饱和。

## 依赖安装

Pi 直连 PyPI 太慢，最后改成在主机下载 wheel、拷到 Pi 上离线安装：
colour-science 0.4.7、numpy 2.2.6，装在项目的 `.venv` 里，系统 Python 不动。
colour 0.4.7 已经不强制依赖 scipy，CRI/TM-30/Ohno CCT 都可以直接用。
